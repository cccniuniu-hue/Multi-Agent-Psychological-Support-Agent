# MindBridge 30 天代码改造与每日推送计划

开始日期：2026-09-14。D01–D06 手动执行；D07–D30 从 2026-09-20 起每天下午 16:00 自动执行，至 2026-10-13。每天以一个可提交的代码切片为目标，并推送到 `git@github.com:cccniuniu-hue/Agent.git` 的 `main` 分支。

## 执行标准

- 每天从当天的任务开始；若前一天未完成，先补齐最早未完成项，再尽力推进当天任务。不可把未实现的功能标记为完成。
- 实现相应功能并检查语法与构建：Java 改动至少执行 Maven `compile`；Python 改动至少执行语法编译；配置文件检查其格式。无需启动 Docker、Ollama、Marker、Chroma、Qwen2-VL 或 reranker，也不把未运行的服务描述成“已跑通”。
- 当天提交包含代码、必要的配置或文档，以及本文件的进度标记。只暂存相关文件，提交前检查差异与敏感信息；不提交 API Key、真实用户对话、模型权重、上传文件或生成的数据。
- 提交后执行 `git push origin main`，再用远程 SHA 验证推送结果。若远程先有新提交，只做安全的 fetch/rebase；遇到冲突、权限或网络问题时保留现场并报告，不强推、不虚报成功。
- 运行前先检查工作区。若有用户未提交的改动，不能混入当天提交；可在独立分支安全完成当天代码，但须明确报告是否已推送及是否进入 `main`。
